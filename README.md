# Rahool & M7QP Ecosystem

**M7QP Token + Rahool AI Integration — BEP-20 on BNB Chain**

---

## 📌 About

**Rahool** is an autonomous AI agent that builds and manages blockchain projects. Our first implementation, **M7QP**, is a BEP-20 token deployed on BNB Chain with a custom **MRGManager** contract for automated liquidity management.

We are building a complete ecosystem that allows users to launch, test, and manage their own digital assets using a dedicated private blockchain for testing and development.

---

## 🎯 Vision

Our goal is to make BNB Chain the easiest place to launch and manage digital assets, using AI to simplify every step.

## 🤖 Rahool AI Agent

**Rahool** is an autonomous AI agent powered by DeepSeek that can:
- Build and manage blockchain projects
- Monitor token activity in real-time
- Manage liquidity automatically
- Provide analytics and reports
- Interact with users via chat

---

## 🛠️ Tech Stack

- **Blockchain:** BNB Chain (BSC), Hyperledger Besu (private)
- **Smart Contracts:** Solidity ^0.8.24
- **Backend:** Node.js, Django, Express
- **Database:** PostgreSQL
- **AI:** DeepSeek API
- **Tools:** Hardhat, Truffle, ethers.js
